## risks
1. The global paint rules (lucide stroke, popover shadow and radius, neutralised resting shadows) reach every screen, including the editor and canvas lucide icons. Both themes need a visual review. With the brand flag off, nothing changes because every rule is gated on <html>.
2. Changing the row height without the placeholder hook makes desktop scrolling jump: off-screen placeholders stay h-11 (44px) while visible rows become 36px or 32px.
3. Styling the shared classes .group/list-block or .group/list-header would misalign the Gantt chart (JS BLOCK_HEIGHT=44, HEADER_HEIGHT=48) and spreadsheet rows.
4. C1 and C2 must land together. With only the new top-bar border-b, the frame's top border stacks into a 2px line. With only the frame removal, the bar has no separator. The fixed workspace dropdown must move from top-10 to top-11, or it overlaps the 44px bar.
5. Frame removal and the row, placeholder, nav-item, peek and chip hooks touch upstream Plane files (content-wrapper, 3 layouts, sidebar-navigation, list/*, list-layout-loader, peek view, dropdowns/buttons). This widens the merge surface for Plane upgrades. Keep each edit to one gated line or an inert attribute.
6. Remapping --text-13 globally for density reflows the entire app: fixed widths such as max-w-[145px] and w-48 panels, and 11px menus. The --text-body-* tokens resolve at :root, so any remap only works on the html element.
7. [id^="headlessui-dialog-panel-"] depends on the Headless UI 1.7.19 id format. Pin it with a test, or use a one-line data attribute in modal-core.tsx instead.
8. [data-popper-placement] only appears after Popper's first update, so a popover shows one frame without its shadow (cosmetic).
9. C8 changes the tooltip trigger from a <button> to a <span>; tooltip hover and focus behaviour and consumers passing buttonClassName must be re-checked.
10. Propel filled icons (about 1.25px) sit next to lucide icons at 1.5px; project navigation mixes both, so their weights will differ slightly.
11. The Power-K modal (a headless Dialog.Panel) will pick up radius 12 and the overlay shadow from the modal rule. This should be checked visually against the wave-0 power-k.css.
