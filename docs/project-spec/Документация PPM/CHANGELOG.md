# CHANGELOG — PPM

## 2026-09-24 — UX0.2 волна 0: токены, доступность, Холст и словарь

Первая (нулевая) волна дизайн-исправлений PPM: не меняет новый облик «гибрид A+B» (отдельная карточка),
только делает текущий интерфейс видимым, читаемым и русским. Патч состоит из 16 последовательных задач (T1–T16)
плюс финальная волна фиксов F1–F8 по результатам ревью; реализовано без git-коммитов поверх рабочего дерева
`plane-fork` (владелец: «без коммитов, патч» — см. «Как доставлен патч» ниже).

**Что изменилось для пользователя:**

- **Токены и темы.** Опасные (красные) кнопки снова читаются тёмным текстом на красной заливке в обеих темах
  (было 1,80:1 тёмная / 3,15:1 светлая, upstream-контраст возвращён); для акцентных (голубых) заливок введена
  отдельная переменная `--txt-on-accent`. Наведение, выделение и слои (`layer-1/2/3`) в дереве Хранилища, вкладках
  администратора, строках задач и на карточках Обзора снова различимы. В светлой теме акцентный текст и ссылки,
  третичный текст и плейсхолдер подняты до ≥ 4,5:1. Фокус-кольцо вынесено из `@layer base` в utilities и видно
  на всех кнопках, включая secondary Propel; фокус визуально отличается от выделения. Светлая-контрастная и
  тёмная-контрастная темы больше не ломаются селекторами бренда.
- **Пропавшие («невидимые») классы.** Найден и устранён источник ~80 несуществующих в собранном CSS классов
  (баннеры ошибок/успеха Хранилища, статусные точки и бейджи Git, тени модалок, `font-mono`, `text-15` и т. п.) —
  заменены на семантические токены Plane. Добавлен постоянный аудит `packages/ppm-brand/scripts/audit-tailwind-classes.mjs`
  (входит в `@ppm/brand test`), который не даёт использовать классы, отсутствующие в собранном CSS. Полоса загрузки
  страницы (`@bprogress`) снова окрашена в акцент PPM, а не в исходный `#2299dd`.
- **«Найти в проекте» вместо «Спросить проект».** Кнопка и панель на Холсте переименованы, агенты и генерация
  ответов ИИ скрыты (решение владельца «PPM 1.0 без ИИ»); остаются поиск по источникам с цитатами, состояние
  индекса с «Переиндексировать» и память проекта. Управляется новым флагом `PPM_PROJECT_ASK_ENABLED`, по умолчанию
  `0` (agents и `answer-runs` не запрашиваются в сети); при `1` возвращается прежнее поведение с агентами. Панель
  теперь имеет один скроллер и не перекрывается тостом (`z-index` поднят).
  См. также [`docs/ppm/antyflow-web-shell-inventory.md`](../../ppm/antyflow-web-shell-inventory.md).
- **Единый статус сохранения Холста.** Раньше состояние дублировалось в трёх местах (точка во вкладке,
  неубираемая карточка, футер). Теперь в футере — единственный текстовый статус; блокирующие состояния
  (восстановление, конфликт, ошибка, повреждение) показываются баннером над Холстом с действиями
  (`aria-live="polite"`, ровно один `.ppm-canvas-status__notice` в DOM одновременно); повтор «только для чтения»
  из футера убран. Служебная «Версия N» заменена на «Доска · обновлена {время}» через пилюлю с раскрывающимися
  деталями (`aria-expanded`, без `role="dialog"`).
- **Боковая рейка Холста.** Свёрнута по умолчанию ниже ≈1280 px, подпись «PPM» вместо «AF/AntyFlow», активный
  инструмент («Холст», «Нарисовать визуальную связь») получил `aria-pressed`, подписи разделов подняты с 9 до
  ≥ 11 px.
- **tldraw в теме PPM.** Цветовая схема холста синхронизирована с темой PPM (раньше в тёмной теме стрелки и текст
  были почти невидимы, контраст 1,06:1); цвет выделения — акцент PPM; шрифт — бренд-шрифт вместо `Inter`.
- **Цвета нод и статусов Холста** переведены на токены с тёмными и светлыми вариантами (было — фиксированные
  пастели без ветвления по теме); ярлык курсора коллеги — контраст ≥ 4,5:1 на всех оттенках 0–359°.
- **Единый русский словарь.** «Рабочий элемент» → «задача», «цикл» → «спринт», «модуль» → «направление»,
  «представление» → «фильтр задач» — единообразно в меню, заголовках, кнопках, крошках и `<title>` через
  RU-оверлей поверх локали `@plane/i18n` (гейт `PPM_SHELL_ENABLED`; при `0` возвращается upstream-строка).
  «Входящие» означает только уведомления; проектный intake называется «Заявки». Автотест не пускает запрещённые
  термины («рабочий элемент», «цикл», «модуль», «представление», «Plane») в эффективный RU-интерфейс.
- **Английские и Plane-остатки на основном пути** убраны: заголовки Черновиков, Заметок и Настроек, `aria-label`
  меню и боковой панели, легенды и оси графиков аналитики спринта/направлений (были «Progress», «Current/Ideal
  work items», «Pending work items», «COMPLETION», «DATE»), состояние сборки в разделе «Код» («в этой сборке ещё
  не…»). Обзор проекта: работающие Хранилище и Код больше не помечены «Запланировано».
- **Поиск команд (Power-K)** сравнивает однобуквенные сочетания через `e.code`, а не `e.key`, поэтому работает в
  русской раскладке ЙЦУКЕН; понимает русские синонимы («спринт», «направление», «фильтр задач», «задача») и
  показывает заголовки результатов по-русски.
- **Доступность и узкие экраны:** верхняя панель на ширине < 640 px сворачивает поиск в иконку, но профиль,
  «Помощь» и уведомления остаются доступны (раньше на 390 px уходили за край экрана, нельзя было даже выйти из
  аккаунта); при свёрнутом сайдбаре на страницах без верхней навигации (Обзор, Хранилище, Код, Входящие) появилась
  кнопка разворота; минимальный кегль на экранах `ppm-*` поднят до 11 px (метаданные) / 12 px (содержательный
  текст); дерево Хранилища получило стрелочную навигацию и `aria-expanded`, вкладки — `role="tab"`/`aria-selected`;
  самописные диалоги Хранилища и Git получили Esc, фокус-ловушку и возврат фокуса, а клик по подложке больше не
  закрывает их и не теряет введённое значение (было регрессией промежуточной волны, исправлено в F2); браузерный
  `confirm()` в Хранилище и Git заменён на подтверждение PPM; все icon-only кнопки получили русский `aria-label`
  (в т. ч. три ранее безымянные кнопки выравнивания текста в редакторе).

**Флаги и откат.** Токены — `PPM_BRAND_ENABLED`; RU-оверлей, глоссарий и оболочка — `PPM_SHELL_ENABLED`; агенты и
генерация ответов на Холсте — новый флаг `PPM_PROJECT_ASK_ENABLED` (по умолчанию `0`). При выключении любого из
флагов возвращается upstream-вид/строки без потери данных и без миграций; данные прежних запусков агентов не
удаляются и не мигрируются.

**Проверки vs baseline** (полные числа — `.superpowers/sdd/2026-09-24-ux02-design-fixes/final-checks.md`):
`packages/ppm-brand` vitest 40/40 → после финальной волны 41/41 (было 19/19, рост без провалов); `@ppm/canvas`
vitest 38/38 (было 37/37), `tsc` — та же 1 старая ошибка `src/index.ts(1803,7) TS2322`, без регрессий; `apps/web`
vitest 167/167 → после финальной волны 184/184 (было 97/97), `tsc` — 0 ошибок (как в базе), `oxlint` — 719
предупреждений/0 ошибок (точное совпадение с базой); `packages/i18n` `sync-check --ci` — 18 локалей × 3837 ключей
(точное совпадение), `check-overlay.ts` — OK; корневой `npm test` — 653/653 (точное совпадение, M0.6 baseline
guard чист, никакого дрейфа манифеста); `packages/propel` и `packages/ui` `tsc` — 0 ошибок. Единственная находка

(`oxfmt --check` — чисто).

**Осознанные отличия от upstream, видимые пользователю** (зафиксированы, чтобы не считаться регрессией при
будущем сравнении с апстримом Plane): цвет спиннера тоста и `!important` у `--bprogress-color` — намеренные
upstream-правки предыдущей волны, в UX0.2 не менялись; сочетание Power-K теперь сравнивается через `e.code`
(раскладка-независимо), а не `e.key`, как в upstream; поведение верхней навигации на узких экранах теперь
целиком гейтируется флагом PPM-оболочки (`isPpmShell`) — при выключенном шелле рендерится ровно upstream-разметка
(это было исправлено отдельно как F4, после того как узкая навигация первой волны T13 была ограничена по флагу).

**Принятые изменения поведения** (осознанное решение владельца/исполнителя, не баг): в полном режиме («Спросить
проект» при `PPM_PROJECT_ASK_ENABLED=1`) порядок блоков панели — запрос → агенты → ответ/прогресс → результаты →
индекс → источники → память, и панель имеет `aria-modal={false}`, потому что пользователь одновременно выделяет
контекст на Холсте.

**Отложено (карточки волны 1 или отдельные решения владельца):**

- переделка вложенных кнопок в выпадающих списках Plane (`dropdowns/buttons.tsx`);
- локализация `@plane/editor` (~150 строк);
- изменения стартовых данных и статусов по умолчанию в API — поэтому у проекта «228» по-прежнему демо-задача
  «Welcome to Plane» и английские статусы (Backlog/Todo/…) как стартовые данные, не как текст интерфейса;
- `@plane/ui Collapsible`;
- передача PPM-флагов (в т. ч. `PPM_PROJECT_ASK_ENABLED`) в Docker;
- термин «рабочее пространство» (workspace) — сознательно не переименован в этой волне.

**Как доставлен патч.** Решение владельца 2026-09-24: без коммитов. Патч UX0.2 собран инструментом
`tools/ux02-diff.sh` и лежит в `docs/superpowers/plans/2026-09-24-ux02/ux02.patch`; исходники файлов до первой
правки сохранены в `docs/superpowers/plans/2026-09-24-ux02/pre/` для отката по каждому файлу отдельно.

## 2026-09-23 — AI-провайдеры и проектные агенты исключены из текущего плана

- По решению владельца I0.9, AF1.1, I1.3 и I1.4 переведены в `deferred` без даты возобновления.
- Их строки убраны из действующего мастер-плана и матрицы требований; прежние идентификаторы и реализация сохранены в историческом архиве.

- Текущий Project Brain ограничен индексированием, поиском, графом, памятью и проверяемыми источниками без AI-модели.
- Матрица desktop→web сохраняет AI/agent строки для истории, но исключает их из parity/release gate.
- Уже написанный код и данные не удалялись; отдельное решение потребуется перед возобновлением этой линии.

## 2026-09-20 — I1.2 Semantic GraphRAG и память проекта переданы на owner review

- Semantic edges получили direction-preserving путь и статус `proposed/confirmed/rejected`; agent-связь не влияет
  на retrieval до явного подтверждения.
- Выбранный Canvas context расширяется только по подтверждённым связям текущего project/board на глубину `0–2`;
  связанный источник получает deterministic bonus, а citation объясняет путь.
- Добавлена Project Memory для решений, дневных, недельных и релизных сводок со снимком source versions/locator,
  proposal review и автоматической отметкой `possibly_stale` после изменения источника.
- Панель `Спросить проект` показывает глубину графа, пути, память и review actions; GraphRAG можно отключить через
  `PPM_BRAIN_GRAPH_ENABLED=0` без удаления данных и без поломки базового retrieval.
- Пройдены 114 backend contract tests, 25 Canvas tests, 35 web tests, typecheck/lint/format, production build и
  локальный browser smoke.

- G1.1 остаётся `in_progress` до создания реального GitHub App и внешнего branch → commit → push → PR gate.

- Добавлены аудит, URL-защита, миграция и contract/regression проверки; карточка G0.1 переведена в `review`.
