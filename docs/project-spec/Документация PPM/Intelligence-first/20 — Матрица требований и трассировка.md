# 20 — Матрица требований и трассировка

Матрица ниже содержит только действующие требования PPM 1.0. Решением владельца
от 2026-09-23 генеративные ответы, AI-провайдеры и агенты исключены из плана;
их прежние идентификаторы сохранены отдельно после матрицы для истории. Project
Brain ограничен индексом, поиском, графом и проверяемыми источниками без AI-модели.

## Исключённые исторические требования

RQ-13 (генеративные ответы), RQ-14 (проектные агенты) и RQ-26 (AI/service nodes)
не входят в действующую матрицу и не проверяются в release gate. Их прежние
формулировки и результаты сохранены в исторических карточках I0.9, I1.3 и AF1.1.
Возврат любой из этих функций потребует отдельного решения владельца и новой
проверяемой редакции плана.

## Правило изменения требований

При добавлении обязательного требования нужно:

1. назначить новый `RQ-*`;
2. указать source-of-truth/архитектурный документ;
3. добавить или обновить task card;
4. указать проверяемый test/gate;
5. обновить changelog;
6. не считать требование выполненным только по наличию UI.

## Definition of covered

Требование считается покрытым документацией, если определены:

- пользовательский результат;
- владелец данных;
- permission boundary;
- API/event либо локальный контракт;
- failure/degraded behavior;
- acceptance test;
- task dependency;
- rollback/disable path.
