# AF1.2 — Realtime и gate полной совместимости AntyFlow

## Пользовательский результат

Команда одновременно работает на общих досках, а web Canvas проходит формальную проверку вида и функций
AntyFlow с документированными безопасными заменами desktop-only механизмов.

## Зависимости и входы

- AF0.1–AF0.5 accepted;
- утверждённая desktop→web parity matrix действующего объёма.

## Scope

- board-scoped realtime rooms, presence, reconnect и authorization invalidation;
- conflict/recovery/offline-safe behavior;
- visual/interaction/node parity suite для текущего объёма;
- desktop board import fixture и migration report;
- performance 300+ shapes и несколько открытых board tabs;
- accessibility, browser matrix, observability и backup/restore;
- финальный список intentional differences с owner approval.

## Фактический прогресс

Первый независимый realtime-срез реализован 2026-09-22:

- API запущен как ASGI-приложение с WebSocket transport;
- Redis channel layer разделяет комнаты по workspace, project и board;
- подключение использует действующую Plane session и повторно проверяет project membership;
- участник и read-only guest видят presence, global admin допускается с audit event;
- heartbeat закрывает соединение после отзыва доступа;
- join/leave/sync и безопасный cursor protocol не передают email, prompts или произвольные metadata;
- web показывает подключение, offline/denied state, число участников и компактные аватары;
- reconnect пережил чистую пересборку и restart API.

Contract suite закрепляет room isolation, запрет outsider/cross-project, read-only guest с отзывом доступа и
cursor allowlist. Полный Canvas API suite — 69 тестов, web suite — 53 теста. Живой Холст показывает
«На доске только вы» через воспроизводимый Docker image.

Пока не завершены операционный merge параллельных правок, отображение удалённых курсоров, conflict/offline recovery,
multi-user E2E, desktop import и полный parity/performance/a11y gate.

## Не входит

- сокрытие отсутствующей функции под названием «эквивалент»;
- cross-project shared board;
- hard delete истории.

## Критерии приёмки

1. Два участника видят изменения одной доски и presence без reload.
2. Участник другого проекта и revoked member не подключаются к room.
3. Global admin подключается к любой доске с audit event.
4. Reconnect/conflict не теряет подтверждённые изменения молча.
5. Все действующие строки parity matrix имеют `done`, `approved replacement` или явный owner-approved non-goal.
6. Desktop fixture импортируется в web без падения и с отчётом по преобразованным нодам.
7. Performance, a11y, restart, backup/restore и security gates проходят.

## Проверки

- multi-user E2E/reconnect/revoke;
- cross-board/project/workspace negative suite;
- visual golden и interaction contract suite;
- performance/browser/a11y;
- migration/import and unknown-node fixtures;
- backup/restore/rollback drill.

## Rollback

Отключить realtime и оставить optimistic save. Отключить новый renderer можно без удаления board data/versions.

## Stop rules

- room authorization не проверяет project scope на сервере;
- reconciliation теряет canonical data;
- parity объявляется без проверяемой матрицы;
- release имеет открытый P0/P1.
