# I0.4 — Web Canvas route и browser-safe AntyFlow core

## Пользовательский результат

Внутри PPM project открывается «Мозг проекта» с AntyFlow/tldraw холстом и локальной note-нoded, используя текущую Plane session и project context.

## Зависимости

- I0.3;
- [../07 — Холст и проекции сущностей](<../07 — Холст и проекции сущностей.md>).

## Scope

- project route;
- browser-safe Canvas package;
- tldraw integration;
- PPM theme;
- node registry;
- `note` и `group`;
- typed visual arrows без semantic persistence;
- loading/empty/error/deny;
- feature flag;
- temporary in-memory/local test store only до I0.5, явно обозначенный.

## Не входит

- server persistence;
- Work Item projection;
- Vault/RAG;
- realtime;
- Electron-only nodes.

## Порядок реализации

1. Инвентаризировать переносимые AntyFlow imports.
2. Создать dependency boundary/test, запрещающий Electron/Node imports.
3. Подключить tldraw совместимой закреплённой версии; при version conflict зафиксировать решение.
4. Создать minimal Canvas shell/toolbar.
5. Реализовать versioned node schema для note/group.
6. Перенести визуальные tokens/motion с reduced-motion.
7. Получить workspace/project context из route/session.
8. Проверить permission read route.
9. Добавить corrupt/unknown node fallback.
10. Выполнить build и manual pan/zoom/create/link.

## Критерии приёмки

1. Route доступен из project navigation.
2. Project context не выбирается повторно.
3. Unauthenticated/outsider получает deny.
4. Note/group создаются и редактируются в текущей сессии.
5. Unknown/corrupt node не роняет Canvas.
6. Web bundle не содержит Electron IPC, `fs`, `better-sqlite3`, webview/terminal/kernel.
7. Остальные project routes работают.

## Проверки

- dependency/import guard;
- node schema/migration unit tests;
- route permission test;
- production web build;
- visual/accessibility smoke;
- project navigation regression.

## Текущее состояние реализации

Локально реализован browser-safe Canvas route внутри текущего Plane project context. В fork добавлен чистый пакет `@ppm/canvas` с версионированной permissive-схемой `note`/`group`, миграцией legacy payload, стабильным fallback для unknown/corrupt нод и изолированным browser persistence key по workspace/project/user. Web-слой использует закреплённый `tldraw@3.15.6`, сохраняет обязательный watermark и не импортирует Electron, Node filesystem, SQLite, terminal или kernel runtime.

Маршрут `Мозг проекта` получает текущие session, workspace и project без повторного выбора. Admin/Member получают редактирование, Guest — read-only, а outsider остаётся за существующим server-backed `ProjectAuthWrapper`; собственных Canvas API и второго auth в I0.4 нет. `PPM_CANVAS_ENABLED=0` скрывает пункт навигации и перенаправляет прямой Canvas route на Tasks без изменения данных.

Пройдены проверки:

- `@ppm/canvas`: 6 unit-тестов, typecheck, build и dependency/import guard;
- `@ppm/brand`: 18 unit-тестов, typecheck, build и audit 23 пользовательских поверхностей;
- `web`: route typegen, полный TypeScript check, lint изменённых поверхностей без ошибок и предупреждений, 13 unit/navigation/access тестов;
- production web build с Canvas и rollback build с `PPM_CANVAS_ENABLED=0`;
- проверка собранного Canvas chunk: запрещённые Electron/Node imports отсутствуют, watermark tldraw присутствует;
- ручной browser smoke: empty state, note/group create/edit, visual arrow, zoom, pan, reload persistence, project isolation и read-only UI;
- локальное хранение явно обозначено как временное до I0.5.

После успешной загрузки закреплённого Plane backend image полный интеграционный auth/outsider smoke повторён на контейнерном стенде 2026-09-13 через реальные project details и membership endpoints Plane API. Результаты: unauthenticated — `401/401`, Admin — `200/200`, Member — `200/200`, Guest — `200/200`, outsider с неактивным project membership — `409/404`. Переключения роли и активности выполнялись внутри транзакции; после отката исходные `role=20` и `is_active=true` подтверждены отдельной проверкой. Тем самым server-backed граница `ProjectAuthWrapper` подтверждена повторно, а прежний сетевой блокер Docker Hub закрыт.

Карточка принята владельцем переходом к следующему этапу 2026-09-13. Коммит выполняется локально; push не выполнялся.

## Rollback

Выключить `PPM_CANVAS_ENABLED`; route скрывается без изменения Plane data.

## Stop rules

- несовместимость tldraw требует случайного major upgrade;
- перенос требует Electron API;
- доступ проверяется только frontend;
- Canvas ломает global routing/build.
