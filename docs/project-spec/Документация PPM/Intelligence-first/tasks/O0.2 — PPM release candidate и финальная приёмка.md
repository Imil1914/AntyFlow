# O0.2 — PPM release candidate и финальная приёмка

## Пользовательский результат

Владелец получает одну проверяемую сборку PPM, в которой роли, AntyFlow Canvas, Work Items, Vault, Brain, Git и
совместная работа проходят единый приёмочный сценарий.

## Зависимости и входы

- все обязательные P0/P1 карточки master plan review-ready;
- O0.1 accepted;
- актуальные matrices 20 и 21.

## Scope

- migration существующих projects/boards;
- E1–E11, Git E2E и cross-project negative suite;
- visual/interaction parity review;
- owner role acceptance;
- legal/source offer и точные revisions;
- release notes, known limitations и rollback rehearsal;
- согласование статусов карточек с фактической сборкой.

## Не входит

- автоматическая приёмка вместо владельца;
- self-hosted Git G2.1;
- скрытие незакрытых ограничений.

## Критерии приёмки

1. Одна сборка проходит обязательные сценарии без ручной подмены данных.
2. Все `done/accepted` требования имеют доказательство проверки.
3. Незавершённые optional функции явно указаны и не выглядят работающими.
4. Rollback сборки и migrations отрепетирован.
5. Владелец отдельно принимает release candidate.

## Проверки

- full regression;
- migration/restart;
- role/isolation/security;
- performance/accessibility;
- legal/source and artifact provenance;
- rollback rehearsal.

## Rollback

Остановить rollout, вернуть предыдущую проверенную сборку и сохранить диагностические данные без удаления
пользовательских документов, досок и Git links.
