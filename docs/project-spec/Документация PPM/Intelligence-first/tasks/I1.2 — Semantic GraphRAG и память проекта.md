# I1.2 — Semantic GraphRAG и память проекта

## Пользовательский результат

Typed Canvas connections и подтверждённые решения влияют на поиск. Project Brain понимает ближайший контекст и сохраняет проверяемую память без превращения summaries в источник истины.

## Зависимости

- I1.1;
- индекс, поиск и evaluation I0.8;
- документы 05/07/08.

## Scope

- semantic edge model/API/UI;
- relation direction/validation;
- selected-node neighbor expansion;
- graph-aware rank bonus;
- confirmed project decisions;
- daily/weekly/release summary records;
- source-version freshness;
- graph retrieval evaluation;
- proposal visual state foundation.

## Не входит

- autonomous background writes;
- cross-project portfolio graph;
- arbitrary ontology editor;
- ML graph embedding unless separately justified.

## Порядок реализации

1. Добавить semantic edge schema/migration.
2. Реализовать typed edge editor and permission.
3. Разделить visual arrows и semantic edges.
4. Реализовать bounded neighbor expansion.
5. Добавить deterministic rank contribution.
6. Добавить citations for edge path.
7. Реализовать memory record/source references/staleness.
8. Добавить golden graph cases.
9. Измерить noise/latency/depth.
10. Обновить query scope inspector.

## Критерии приёмки

1. Typed edge сохраняется и переживает reload.
2. Directional relations не инвертируются.
3. Depth ограничен и виден пользователю.
4. Связанный источник поднимается в релевантном golden query.
5. Edge citation объяснима.
6. Summary с изменённым source помечается stale.
7. Неутверждённая связь не считается confirmed.
8. Cross-project graph traversal невозможен.

## Проверки

- relation schema/direction;
- graph traversal boundaries/cycles;
- ranking golden suite;
- stale memory;
- permission/leakage;
- performance/depth;
- no-graph fallback.

## Реализовано 2026-09-20

- semantic edge получила направление, тип, происхождение и явный статус `proposed/confirmed/rejected`;
- agent-связь не участвует в retrieval до подтверждения РП/редактором, а повторное review отклоняется;
- выбранные Canvas nodes расширяются только по подтверждённым связям той же доски и проекта на глубину `0–2`;
- путь до источника сохраняет исходное направление связи и показывается в citation/query inspector;
- deterministic graph bonus поднимает связанный источник, не меняя обычный поиск без выбранного контекста;
- добавлена Project Memory для решений, дневных, недельных и релизных сводок со снимком версии и locator каждого
  источника;
- пользовательская запись подтверждается сразу, agent-запись остаётся proposal до проверки; изменение source version
  переводит запись в `possibly_stale` без скрытого переписывания текста;
- панель `Спросить проект` показывает глубину обхода, путь связей, состояние памяти и действия confirm/reject;
- `PPM_BRAIN_GRAPH_ENABLED=0` отключает обход и rank bonus, сохраняя базовый поиск, выбранный источник и данные.
