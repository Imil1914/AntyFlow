# AF2.1 — Инструменты Холста: панель по группам, стикеры, схемы, заметки, код, файлы

## Пользовательский результат

На Холсте удобно и быстро работать руками, как в привычных досках: панель инструментов сгруппирована, есть стикеры,
фигуры для схем с «+» для продолжения, цвет у любого объекта, заметки с форматированием и формулами, блок кода,
вставка картинок из буфера и любые файлы с просмотром и скачиванием. Всё, что было сломано или потеряно, снова работает.

Это подпроект П1 программы «Холст 2.0» (П1 инструменты → П2 «Живая карта проекта» AF2.2 → П3 «Комментарии и совместная
работа» AF2.3). Решения владельца 2026-09-25: главный сценарий — «Карта проекта» (еженедельная планёрка); сервер можно
менять; порядок П1 → П2 → П3; дизайн П1 утверждён, «делай до конца» без промежуточных согласований; без коммитов.

## Scope

### A. Панель инструментов по группам (K1)
- Плавающая вертикальная панель на холсте (облик волны 1): Выбор (V), Рука (H) | Стикер (S), Текст (T), **Фигуры ▸**,
  Перо (P), Рамка, Связь | **«Документы и текст» ▸** (Заметка, Документ, Список, Таблица, Код, Схема), **«Из проекта» ▸**
  (Задача, Доска задач, Файл, Git-объект, Документ PPM), Смысловые связи | **«Ещё» ▸** (Найти в проекте, импорт/экспорт,
  объекты доски); отменить/повторить.
- Меню группы — как в K1: заголовок, подпись, пункты с пояснением; сочетания клавиш — только реальные.
- Фигуры ▸: прямоугольник, скруглённый, овал, ромб, треугольник, шестиугольник, параллелограмм/трапеция, облако,
  стрелки-блоки (из набора geo tldraw 3.15.6).

### B. Стикеры, фигуры, связи, цвет (K2, K3)
- Стикер — нативная заметка tldraw (`note`): пишешь сразу; цвет из палитры PPM; размер текста S/M/L; жирный — если
  поддерживается редактором текста tldraw.
- Фигуры — нативные `geo` с подписью внутри; связи — стрелки tldraw с подписью, привязанные к фигурам; из одной фигуры —
  сколько угодно связей.
- «+» продолжение: у одной выделенной фигуры — 4 «+» по сторонам; клик → меню «Продолжить: прямоугольник · ромб · овал ·
  параллелограмм · ещё» → новая фигура рядом без наложения, связанная стрелкой, сразу в режиме ввода; перетаскивание «+»
  — стрелка к точке или к другой фигуре.
- Цвет у любого объекта: компактная панель над выделением (цвет, размер текста, шрифт/заливка/форма — по типу объекта).
  Палитра PPM: 8 оттенков равной светлоты + нейтральный (K3); для нативных фигур — через палитру темы tldraw, для
  карточек PPM — поле цвета в схеме узла (с миграцией).

### C. Заметка, документ, список, таблица, код (K3)
- **Заметка** (карточка PPM на доске): Markdown (заголовки, списки, ссылки, код с подсветкой), формулы LaTeX (`$…$`,
  `$$…$$`) через KaTeX; просмотр — отрисованный текст, двойной клик — правка; «Сделать задачей» (создаёт задачу Plane,
  карточка задачи рядом), «Сделать документом» (создаёт документ в «Документах», карточка документа рядом).
- **Документ** — живая карточка «Документов» PPM (Plane Pages): «Новый документ» (создать страницу и положить карточку),
  «Документ PPM» из «Из проекта» (найти существующую), превью текста, «Открыть ↗». Формулы в редакторе «Документов» —
  отдельная задача в конце плана (расширение редактора), если укладывается.
- **Список** — чек-лист; «Сделать задачами» для отмеченных пунктов.
- **Таблица** — как сейчас (+ исправления второго агента).
- **Код** (как на фото владельца): номера строк, язык с подсветкой (lowlight/highlight.js), светлая/тёмная тема блока,
  замок «только чтение», меню «…»: копировать, скачать файлом, перенос строк.
- «Схема» в «Документы и текст» открывает те же фигуры для блок-схем.

### D. Файлы и вставка (K4)
- Ctrl/⌘+V картинок и фото из других приложений, перетаскивание файлов, ⌘U — через обработчик внешнего контента tldraw
  → загрузка в Хранилище (понятное имя, например «Вставка-2026-09-25-153012.png») → живая карточка; в снимке доски
  не остаётся base64.
- Файлы любых поддерживаемых Хранилищем форматов; просмотр: картинки, PDF (надёжно, не через плагин в песочнице),
  текст/Markdown/JSON/CSV/код (с подсветкой); Word/Excel/PowerPoint — превью, построенное сервером из содержимого
  (текст, таблицы, слайды) с кешем; остальное — иконка и «Скачать».
- У любой файловой карточки — «Скачать» и полноэкранный просмотр.
- Аудио/видео — если сервер примет форматы и отдаст файл с поддержкой диапазонов; иначе — вне AF2.1 (фиксируется).

### E. Исправления после второго агента
- Вернуть: вход в «Смысловые связи» (рейка и палитра, для читателя — только чтение), масштаб в облике v1, создание
  секций/рамок, рабочую «Доску задач» (канбан) вместо заглушки; убрать тихое ужатие досок задач (запись без действия
  пользователя); правая панель задач не перекрывает инспектор; единый счётчик объектов.
- Облик v1 (откат `PPM_DESIGN_V2=0` или `localStorage.ppm_design="v1"`) — как в конце волны 1 (UX1.1), плюс исправление
  кликов; всё новое — только под v2.
- Сохранить полезное: клики в карточках, раскладку без наложений, чек-лист/таблицу, ссылки на доску и задачу, фигуры,
  перо, текст, панель «Задачи и бэклог».

## Не входит

  рамок, экспорт PNG/PDF, шаблоны, майнд-карта — позже.

## Контракты и инварианты
- I1/I2: задача, документ, файл живут в своих источниках; на доске — ссылка и визуальные свойства; «Убрать с холста» ≠
  удалить источник; «Сделать задачей/документом» создаёт источник через его API и кладёт живую карточку.
- Схема узлов версионирована: новые поля (цвет из палитры, формат заметки, поля кода) — с миграцией и тестом; старые
  доски открываются без потерь; неизвестные поля сохраняются.
- Без ИИ; без новых внешних запросов (KaTeX, шрифты, подсветка — локально); вставка URL не ходит в сеть из браузера.
- Безопасность: Markdown санитизируется (DOMPurify), без исполнения кода и HTML; превью Office строится сервером без
  исполнения макросов; лимиты размера и защита от zip-бомб; права Хранилища и Документов проверяет сервер.
- Горячие клавиши — `e.code`; строки — в модулях переводов `@ppm/brand` (en и ru).
- Производительность: 300 фигур без просадки; оверлеи («+», панель стилей) не пересоздают холст.

## Критерии приёмки
1. Все пункты панели работают на тестовой доске: стикер, текст, фигуры, перо, рамка, связь, заметка, документ, список,
   таблица, код, задача, доска задач, файл, Git-объект, документ PPM, смысловые связи.
2. «+» создаёт связанную фигуру за один клик; у одной фигуры ≥ 4 связей; цвет меняется у фигуры, стикера и карточки PPM.
3. Формулы LaTeX отображаются в заметке; блок кода — с номерами строк, подсветкой, замком; «Сделать задачей» создаёт
   задачу Plane.
4. Вставка картинки из буфера кладёт живую карточку файла Хранилища; в снимке доски нет `data:`; «Скачать» и просмотр
   работают для картинки, PDF, Markdown, кода, docx/xlsx/pptx.
5. Регрессии раздела E исправлены; облик v1 — как в конце UX1.1; старые доски открываются.
6. Проверки не хуже базовой линии (web vitest, brand, canvas, root, tsc 0, oxlint 719/0), новые тесты зелёные; живая
   проверка на доске «Тест Холста» в проекте 228 (разрешено владельцем).

## Решения исполнителя
| # | Вопрос | Решение |
|---|---|---|
| R1 | Стикер: свой или нативный | Нативная `note` tldraw (ввод, рост, клон-«+» у стикера из коробки), палитра PPM через `DefaultColorThemePalette` |
| R2 | Фигуры и связи | Нативные `geo` и `arrow` tldraw с привязками; «+» — свой оверлей (`createShape` + `createBindings`) |
| R3 | Панель стилей | Своя компактная (`TldrawUiContextualToolbar` + `setStyleForSelectedShapes`), стандартную StylePanel не включаем |
| R4 | Markdown/формулы/подсветка | marked + DOMPurify + KaTeX + lowlight — пакеты уже в lock/store; подключаются в apps/web офлайн (corepack pnpm) |
| R5 | Вставка файлов | Вариант A: `registerExternalContentHandler('files')` → Хранилище → живая карточка; миграция старых `data:` — отдельной задачей |
| R6 | Office-превью | Серверный эндпоинт (zipfile + lxml + openpyxl, уже в зависимостях API), кеш по хэшу, лимиты |
| R7 | Облик v1 | Как в конце UX1.1 (+ исправление кликов); новое — под v2 |
| R8 | «Доска задач» | Восстановить рабочий канбан (клики теперь проходят); без автоужатия |
| R9 | Версия схемы узлов | Остаётся 2 (её закрепил сервер); новые поля обратно совместимы, значения по умолчанию при чтении |
| R10 | Лимиты Markdown | Форматирование до 10 000 знаков и линейная оценка «тяжести» разметки; сверх — простой текст с пояснением (защита всех зрителей доски от зависания) |
| R11 | Документы на общих досках | Только общедоступные: название документа сохраняется в доске; поиск документов для Холста отдаёт только общедоступные страницы верхнего уровня |
| R12 | Гости | Правило Plane: гость без расширенного доступа видит на Холсте только свои документы (поиск и карточки) |
| R13 | ⌘Z после переноса картинок | Картинка возвращается, карточка Хранилища остаётся (как у всех живых карточек); повторный перенос не создаёт дублей |
| R14 | Превью Excel | Только значения ячеек (листы, строки, стили дат); диаграммы, картинки и прочие части в разбор не попадают; лимит 5 МиБ на часть, не больше 2 разборов одновременно |
| R15 | «Из проекта → Файл / Git-объект» | Файл — выбор из Хранилища или «Загрузить с компьютера…»; Git-объект — переход на страницу кода проекта, откуда «На холст» возвращает объект |
| R16 | Новая заметка | Сразу открывается для ввода (как стикер) |
| R17 | Замок блока кода | Запертый блок не меняется ни у кого (язык, тема, перенос), пока его не откроют; копировать и скачать можно всегда |
| R18 | Форматы вставки | Клиент принимает ровно то, что принимает Хранилище (в т.ч. GIF и исходный код); лимит 5 МиБ проверяется до загрузки |
| R19 | Несколько открытых досок | Фокус, вставка и горячие клавиши — только у открытой вкладки (исправление давней ошибки, найдено на живой проверке) |
| R20 | Вставка ссылки в облике v1 | Как в UX1.1 (стандартный путь tldraw); запрет сетевых запросов при вставке ссылки — только для нового облика |
